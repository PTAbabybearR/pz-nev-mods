# 核心库 NEV Lib 更新日志

## v1.5.0（未上传；和理想L6 v1.5.0、Cybertruck v1.1.0 同一次发）
- **车辆整体数值重新调教：车更轻、加速放慢、高速急转更稳（#368，用户试车）**：理想L6、Cybertruck 两车的质量按新的重量尺子整体下调；0–100 km/h 加速放慢到约 Cybertruck 6.5 秒、理想L6 7.5 秒（以前更快）；侧倾调到 0.98（和野马终极首领一样），重心降低，悬挂照野马换算，空载、满载满速急转都不撞地（用户 10-29、10-30 试车）。满载的 Cybertruck 高速急转时车身可能极轻微擦地，不掉血，开起来感觉不到。往前开的极速封顶在原版 SUV 的水平（约 110 km/h）；倒车极速两车统一（约 20 km/h）；满载不再按重量限速。老存档：质量、侧倾、重心、悬挂读档即生效；推力只对新生成的车生效。设计：DESIGN 5.4、5.5（#368，修订 42、43）
- **和别的仪表盘 mod 一起用（#339）**：以前装了 Banger's Retro Car Dashboard 这类换掉原版仪表盘的 mod，新能源车的仪表盘会消失，或者两套叠在一起；现在可以一起装。坐在理想L6、Cybertruck 的主驾时，只显示我们的仪表盘；坐别的车，或者坐新能源车主驾以外的座位，交给原版或那个 mod，和没装我们的 mod 时一样。mod 列表里谁在前谁在后结果都一样，不用调顺序。实测过 Realistic Dashboard & Gauges [MP]、Retro Dashboard Digitals、Banger's Retro Car Dashboard [B42]：单机三个都试了前后两种顺序，前两个还在专用服务器联机上试过。装过玩家补丁「NEV-Realistic Dashboard Fix」的，现在已经不需要它了：进游戏时会提示一次，补丁不再起作用，请在 mod 列表里停用。设计：DESIGN 11（#339，修订 37）
- **先坐理想L6 再坐 Cybertruck 时，仪表盘偏右（#339，实机测试发现）**：同一局里先坐过理想L6、再上 Cybertruck，Cybertruck 的仪表盘不在屏幕底部正中，而是往右偏一截。现在不论先坐哪辆车，仪表盘都在屏幕底部正中。设计：DESIGN 11（#339，修订 37）
- **仪表上的充电口方向更好认，档位 P 不再发暗（#338，玩家反馈）**：电量、油量图标右下角表示充电口（加油口）在车哪一侧的小三角放大了一些，位置不变；断电后仪表收成窄条时，窄条中间也会显示插头和它的方向三角，增程车再加油枪和它的方向，鼠标停在上面会显示电量（油量）提示，断电但在充电时仪表照常展开、不会重复显示；停车时档位 P 改成和 D、R 一样的正常颜色（以前是暗灰色，不好认）。定速巡航的显示和原版一样，不变。设计：DESIGN 11（#338，修订 39；设计稿 dashboard-design 第 26 节）
- **车顶行李架坏了可以修理了（#351，自测）**：以前车顶行李架（SUV 类、皮卡类）耐久掉了以后修不了，只能换件；现在从车上拆下来，在背包里右键就能「修理」，修法和原版车的后备箱一样：喷灯（用 2 次）加 1 张金属板或 2 张小金属板，需要金属焊接 3 级、机械 2 级，修好后耐久回升。材料或技能不够时选项是灰的（和原版一样）。理想 L6、Cybertruck 的行李架都能修，老存档里已有的行李架也一样。其余车上物品照原版思路处理：车身件能修，动力电池、中控屏、冰箱和原版的电瓶、收音机、手套箱一样算耗材，坏了换件。设计：DESIGN 9.1「行李架修理」（#351，修订 35）
- **联机时车门、机盖、尾门的画面跟上真实状态（#337）**：多人服务器上，别的玩家开关新能源车的车门、机盖、尾门时，你这边画面不跟着动，看起来「门关不上 / 一直开着」；现在附近的车会按真实状态显示，开关时也会播动画。自己上下车或开关门后偶尔停在错的姿势，现在约 2 秒内会自动摆正。只影响联机，单人游戏不变；原版车不在范围内。设计：DESIGN 13.6（#337，修订 38）
- **站在很多新能源车中间时客户端更省（#327，自测）**：联机时站在一大片新能源车中间，客户端每秒花在本 mod 上的时间大幅减少：30 台理想L6 中间，从约 7.6 ms/秒降到约 1.7 ms/秒（受入实测 1708.3 µs/秒，上限 2000）。帧率改前就不受影响，改后也一样（受入实测帧率 p5：新能源车组 49.51 / 原版车组 49.28），这次省下来的是 CPU。玩家能看到的变化：装上或拆下防撞杠、车窗护网之后，模型最晚 0.5 秒跟上（原来最晚约 0.08 秒）；摇车窗时，10 格以内的车窗护网照旧立刻跟上，10〜30 格外的车最晚 0.5 秒跟上；开关门（篷布等随门隐藏的零件）照旧立刻跟上；空气滤网照旧挡异味，包括读档时已经坐在车里、刚上车的头几秒、联机里别的玩家进车。设计：DESIGN 13.5、13.6（#327，修订 36）
- **源代码已开源（MPL-2.0），美术资源保留所有权利（#344 / #349 / #350，用户 10-23）**：mod 包里的许可文件换成三份：`LICENSE.txt`（代码：Lua、游戏脚本、翻译，按 Mozilla Public License 2.0，可以商用、可以改了再发布，改过的文件要同样公开）、`LICENSE-ART.txt`（模型、贴图、图标、界面图片等美术：作者保留权利；可以游玩、录视频直播、在合集里链接，也可以照我们的贴图画皮肤做成单独的附加 mod；不可以重新上传或放进整合包）、`NOTICE.txt`（沿用游戏原版的部分仍归 The Indie Stone，商标声明）。以前的版本照旧适用当时的许可。设计：无（发布许可的变更，开源方案第 3、5 节）

## v1.4.1（2026-10-23 上传，tag `NEVLib-v1.4.1`；只发核心库，理想L6、Cybertruck 不变）
- **装甲读档后照样起作用（#336）**：以前读档（以及走远再回来、车所在区块重新加载时偶尔）以后，装着的防撞杠、挡风装甲、车窗护网、车门护甲板、轮胎护板全部不再起作用，撞僵尸时引擎盖、大灯、车窗、轮胎照样掉耐久，要拆下重装才恢复；现在读档后、区块重载后都照常把掉的耐久从装甲补回。单机和联机（专用服重启后）都一样。失效期间已经掉的耐久不会补回来。设计：无（只修实现没生效，DESIGN 9.1「服务端每 0.25 秒检查装甲车、被保护部件掉的耐久从装甲填回」的规则不变）
- **前防撞杠现在也护驱动电机（#336）**：设计上前防撞杠护「引擎盖、驱动电机、两个前大灯」，但 1.3.0〜1.4.0 实际没护到驱动电机（电机部件没有物品，被当成「部件掉了」跳过）；现在电机掉的耐久同样从防撞杠补回、防撞杠照常扣。极少数情况下一下撞击把电机直接打到 0，到下一次检查（最长 0.25 秒）补回之前，引擎可能熄火一次。设计：无（只修实现没生效，DESIGN 9.1 本来就写着前防撞杠护「车头：引擎盖、驱动电机、两个前大灯」）
- **空气净化的内部记录不再一直留着已离开的车（#328）**：坐过一台新能源车后，空气净化为它记下的一条「门窗关没关好」的结果，以前在车离开世界（开远了、车被卸载）后还会一直留在内存里，直到游戏回收那台车为止；现在过了 1 秒就清掉，每秒最多清一次，没人坐车时什么都不做。玩家看到的空气净化规则不变（门窗关好才过滤、开门后最多 1 秒停止过滤），联机、单机都一样，性能和以前相同。设计：无（只改内部缓存的清理，DESIGN 13.6 ③「密封结果缓存 1 秒」的语义不变）

### 已知问题
- **联机时车门关不上、一直显示开着（#337）**：多人服务器上，用原版菜单上车（开门 → 进车 → 关门）或在车外开关门后，自己画面里的车门常常停在「开着」，关门看起来无效；别的玩家看到的门也可能停在车载入时的样子。门实际的开关状态大概率是对的，错的是画面。理想L6、Cybertruck 都会出现，单人模式没有这个问题。原因是原版游戏联机时带开关门动画的车门画面不同步，我们的车门有动画所以暴露出来；准备在核心库里修。设计：无（原版引擎联机门动画不同步，修复在 #337）
- **和整块替换原版仪表盘的 mod 冲突，如 Realistic Dashboard & Gauges（#339）**：同时装了 Realistic Dashboard & Gauges（「真实仪表盘」）、Banger's Retro Car Dashboard 这类整块替换原版仪表盘的 mod 时，按加载顺序，新能源车上我们的仪表会整块消失（电量、续航、能量模式、充电剩余时间都看不到），或者和对方的仪表叠在一起、门 / 灯 / 暖风图标显示不出来；能量模式等操作在径向菜单里仍可用，油车不受影响。准备把我们的仪表改成独立面板，不再和原版仪表抢。设计：无（兼容性问题，修复方向在 #339）

## v1.4.0（2026-10-21 上传，tag `NEVLib-v1.4.0`；和 Cybertruck v1.0.0、理想L6 v1.4.0 同一次发）
- **皮卡类装甲 / 选装件（#272，用户 10-18）**：新增皮卡类一整套，同类皮卡通用：车门护甲板（挡在车门和车窗外面，作用同车窗护网——保护车窗和车里的人，车门本身被撞照样会坏）、前挡装甲、后挡装甲、前防撞杠、后防撞杠、车顶行李架、轮胎护板；除行李架外都有普通 / 优秀两档，没有猫耳彩蛋。重量、配方（金工等级、材料、时间）和 SUV 类对应件一样，读「新能源皮卡改装手册」后能做，手册和 SUV 手册在同一批地方、同样少见。车上的样子由车型包提供（Cybertruck 另行更新）；拆下来掉在地上的样子和背包图标都是正式的：轮胎护板是带加强筋的钢圆盘；车门护甲板、前 / 后挡装甲、前 / 后防撞杠、行李架照 Cybertruck 车上那件的形状做（枪灰钢板、铆钉；行李架是横杆上一个篷布包），优秀档图标右上角有金色角标。设计：DESIGN 9.1（#272，修订 21）
- **轮胎护板（#272，用户 10-18）**：装甲第一次能保护轮胎：装着轮胎护板时，开车磨损、撞 / 碾僵尸掉的轮胎耐久都由护板承担（磨 1 点护板只掉约 0.1），轮胎不会因为耐久低而爆胎；漏气不管，照常打气；换轮胎前要先拆护板。设计：DESIGN 9.1（#272 / #286，修订 21）
- **SUV 类轮胎护板（#286，用户 10-18）**：SUV 类也有了轮胎护板（普通 / 优秀两档），规则和数值同皮卡类轮胎护板；「新能源 SUV 改装手册」也教它的配方。车上的样子由车型包提供（理想 L6 另行更新）；拆下来的样子和背包图标同皮卡类轮胎护板（按 L6 的轮胎做小一号）。设计：DESIGN 9.1（#272 / #286，修订 21）
- **车顶行李架站在车两侧也能取放（#300，用户 10-18）**：以前只能站在车后取放行李架里的东西，现在站在车后、车左侧或车右侧（车门、车轮旁边）都行；坐在车里、站在车头前面或离车太远仍然不行，没装行李架照旧不能用。所有带行李架的新能源车（现在是理想 L6）同时生效，老存档里的车也一样。设计：DESIGN 9.1（#300）
- **分体防撞杠的上块随尾门显示（#296，用户 10-18）**：车型包可以把防撞杠的车上模型做成上下两块（游戏里仍是一个部件，照旧固定在车身上、不锁尾门），上块挂在尾门上、开尾门时跟着抬起；尾门拆掉时上块不显示（不会悬在半空），装回尾门又出现，下块一直在。读档、联机另一端看到的都一样。没有分体模型的车和部件（前防撞杠、Cybertruck）不受影响。设计：DESIGN 9.1（#296）
- **前备箱（#306，用户 10-18）**：新能源车可以有第二个储物格「前备箱」：站在车头前、打开前备箱盖（原版的「打开引擎盖」）就能取放，盖关着不行，盖被拆掉时直接能取放；坐在车里、站在车尾或两侧都拿不到。装着前防撞杠照样能开盖取放。容量按真车升数换算；前备箱本身（约 40）和装进去的东西都算车重。用原版小后备箱物品，不能拆装、可以修。哪台车有由车型包决定（真车有前备箱的才有；理想 L6 没有，Cybertruck 首发带）。设计：DESIGN 9.3（#306，修订 33）
- **维修界面里装甲部件的名字（#273，用户 10-19）**：轮胎护板在维修界面里显示成「IGUI_VehiclePartNEVTireGuard…」这样的原始键名，现在显示「左前轮胎护板」等；车型包可以给自己的装甲部件起名（护甲声明里写 `name`），Cybertruck 的车门护甲板显示「左前门护甲板」等、不再显示成「左前车窗护网」。理想 L6 的名字不变。设计：无（界面文字修正）
- **装得越重最高速越低（#226 后续，用户 10-19）**：车重（含装着的选装件和容器里的东西）超过 1600 后自动限最高速：1601–1800 约 80、1801 以上约 75 km/h，卸货后恢复，空车和轻载照常跑。所有新能源车共用这张表；和电池耗尽时的限速同时出现时取较低的那个，不弹「亏电限速」提示。满载急刹打方向不容易甩尾打转；代价是满载高速时方向会沉一些（电池耗尽限速时也是这样）。注意原版放进后备箱的东西要等车重刷新（例如读档、油量变化）才算进车重，限速也跟着那时才变。数值按实机测定：限速下满载急刹打方向，甩的程度和原版 SUV 在 90 km/h 时差不多。设计：DESIGN 5.4（P8，#226，修订 26 / 28）

- **装着车窗护网也能摇窗开枪（#317，用户 10-19）**：以前装着车窗护网（SUV 类）/ 车门护甲板（皮卡类）时车窗摇不下来，坐在车里没法往外开枪；现在可以照常摇下。摇下时这一侧的护网 / 护甲板在车上看不见了（让开），也不防护、不掉耐久，人和原版一样露在外面——能往外开枪，僵尸也能抓到；摇上后护网回来，照旧防抓。护网一直装在车上，不用拆。装护网时车窗仍会自动摇上。读档、联机另一端看到的都一样。所有装护网的新能源车（理想 L6、Cybertruck）同时生效，老存档里的车也一样。设计：DESIGN 9.1（#317，修订 29）
- **联机时两人同用一个地上的储能电源补电（#321）**：多人服务器上两个玩家同时用同一个放在地上的储能电源给各自的车补电（或充电），离储能电源稍远的那个人以前一点电也充不进、服务器报错；现在两人都能补，电量按各自实际补进的从储能电源里扣。单人模式不受影响。设计：DESIGN 6.4（#321，修订 30）
- **新刷出来的车冰箱先不工作（#319，用户 10-19）**：以前地图上刷出来、从没人开过的车，冰箱一开始就在制冷耗电（最多 24 游戏小时）；现在从没通电过的车冰箱不制冷、不耗电，开关仍是「开」，玩家第一次给车上电（开车或露营）后才照常工作，下电后照旧最多再工作 24 游戏小时。老存档里开过的车不受影响；从没开过的车同样改为先不工作。设计：DESIGN 7.1（#319，修订 30）
- **仪表盘数字每 0.25 秒刷新一次（#320，用户 10-20）**：车速、电量 / 油量（百分比和电量条长度）、续航、时间日期温度、充电剩余时间改为每 0.25 秒更新一次（以前每帧），看起来仍是连续变化；图标灯（冰箱、露营、净化、增程器等）、档位、能量模式按钮和各种动画照旧即时。坐在新能源车里时仪表盘占用的电脑性能更少。设计：DESIGN 11（#320，修订 30）
- **联机时下车再上车，暖风和中控屏的开关对不上（#322）**：多人服务器上开着暖风下车、再上车时，车按记忆把暖风恢复成开（在制热、在耗电），但所有玩家看到的暖风仍是关；露营中车里没人、关掉露营后车随之断电，玩家看到的暖风还是开。中控屏（收音机）同样：断电后玩家那边仍显示开着，再上车恢复时也对不上。现在服务器和每个玩家看到的一致。单人模式不受影响。设计：DESIGN 13.6（#322，修订 31）
- **开车时打开露营，暖风不再被关掉（#324）**：以前开着暖风 / 空调开车，打开露营模式后暖风会自己关掉（露营本来就是为了停车时保持车内温度）；现在暖风保持原来的开关和温度设定，单人和联机都一样。下车断电时暖风照旧关闭、再上车恢复。设计：DESIGN 7.2（#324，修订 31）
- **联机时仪表盘续航估算一直用默认能耗（10-21）**：多人服务器上，仪表盘的续航和提示里的「kWh / 100 km」一直按车型默认能耗算，不跟随实际驾驶（开得快续航也不掉、开得慢也不涨），只有服务器自己知道最近的能耗；现在最近能耗变化到提示里显示的那一位（0.1 kWh / 100 km）时同步给各玩家，续航跟着实际驾驶变化。单人模式不受影响。设计：DESIGN 13.6（修订 32）

### 已知问题
- **联机时两人同时从同一个容器拿同一件东西，偶尔两人都拿不到（原版问题，10-21）**：多人服务器上两个玩家几乎同时去拿同一个容器里的同一件东西时，大约 1/255 的机会两个人都拿不到——东西留在原处，动作照常结束，没有任何提示或日志；再拿一次就正常。这是原版游戏（B42 42.21）的问题，所有容器都会出现（地上、家具、尸体、任何车的储物格），不只新能源车的冰箱，和本 mod 无关、本 mod 也修不了。原因：每个玩家给自己的取放动作从 1 开始编号，服务器取消某个动作时只按编号删、不看是哪个玩家的；两人编号碰巧相同时，后到那人的动作被拒绝后会顺手把先到那人已经批准的动作也删掉（`TransactionManager.removeItemTransaction` 按编号 `removeIf`）。设计：无（原版问题）
