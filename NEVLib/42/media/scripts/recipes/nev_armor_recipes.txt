       NEVMake<Class><Piece>[Fine], taught by the class manual (NEVLib.Manual_<Class>, NeedToBeLearn); the
       metalworking level stays a gate too. The Fine grade = the normal recipe with its first (main) input x 1.5
       rounded up (tools/check_static.py armor-classes). Welding with vanilla materials only (user 2026-10-12 /
       2026-10-15). Blow torch inputs count uses (InputScript: a drainable without mode / ItemCount); the mask is
       kept. Times sit between vanilla's MakeMetalSheet (250) and the scrap armour (600). */
    craftRecipe NEVMakeSUVWindowGuard
    {
        timedAction = Welding,
        NeedToBeLearn = true,
        time = 300,
        SkillRequired = MetalWelding:4,
        Tags = InHandCraft;Welding,
        category = Metalworking,
        xpAward = MetalWelding:15,
        inputs
        {
            item 1 [Base.SheetMetal],
            item 2 [Base.SmallSheetMetal],
            item 2 [Base.BlowTorch],
            item 1 tags[base:weldingmask] mode:keep,
            item 1 tags[base:sheetmetalsnips;base:metalsaw] mode:keep flags[MayDegradeLight],
        }
        outputs
        {
            item 1 NEVLib.SUV_WindowGuard,
        }
    }
